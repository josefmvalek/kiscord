- **`#návyky`** (`js/domains/lifestyle/habits.js`) — Daily habit streaks with Love Coins rewards.
- **`#bucket-list`** (`js/domains/lifestyle/bucketlist.js`) — Shared dream bucket list with priorities & completions.
- **`#timeline`** (`js/domains/lifestyle/timeline/`) — Memory photo timeline with lightbox gallery, polaroid album mode, and date sorter.
- **`#plánovač-rande`** (`js/domains/lifestyle/date-planner/`) — Interactive Leaflet map with pinned date spots and routing.
